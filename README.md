# KEMP EYE RESONANCE 👁

## 12-Day Resonance Practice

A simple experience-first mobile project.

**No interpretation. No expectation. No reporting.**

Each day presents only the experience and a PLAY control. The soundscape is designed to change across all 12 days.

The project uses the existing Day 1–12 narration/audio source from `112-days-`; that repository is not modified by this project.

## GitHub Pages

The repository contains a root `index.html`, which is the entry point for GitHub Pages. GitHub Pages can publish static HTML directly from a repository.
